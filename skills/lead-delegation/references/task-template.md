# 委派任务模板

复制到 scratchpad 的 `task-<主题>.md`，把每项换成任务事实。

| 项目 | 写入内容 |
|---|---|
| 背景 | 已核实的事实、复现结果、`文件:行号`。要求先核实再动手，事实有出入时先汇报。 |
| 决策与交付 | 用户决定的原话、可验收的结果、要原样使用的界面文案。新能力、公共契约或跨包改动按项目要求建 OpenSpec，建好后直接实现。 |
| 工作区与边界 | 路径、分支、允许修改的文件。写明需保留的未提交改动、其他会话正在改的文件，以及每项适用的项目限制，例如服务启停、服务器只读、受保护目录。 |
| 权限与取舍 | Pi 只修改任务所需的代码、测试和必要注释。提交、推送、服务启停、文档与 Skill 正文由主导者处理。复用项目实现，避免重复校验和额外抽象。无法可靠实现时停下并说明阻塞。 |
| 验证 | 写明具体的聚焦测试和必要的受影响包检查命令，遵守项目验证预算。最后一次相关修改后验证通过即完成，修复后重跑受影响的失败项。全仓检查仅在项目要求或影响范围确有需要时执行。 |
| 汇报 | 列出改动文件、实际执行的命令和结果、未验证项。界面改动附手机宽度截图。 |
