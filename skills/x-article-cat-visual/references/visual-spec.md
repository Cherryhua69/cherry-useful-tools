# V4.0 视觉规范｜布偶猫角色、语义与出图细则

## 角色身份（原始参考图优先）

- 蓝色明亮大眼、细腻虹膜光泽，禁止变绿或变黄。
- 奶油白蓬松长毛；浅灰棕重点色在耳朵、脸外侧和蓬松尾巴；面部中心偏奶油白。
- 圆润幼态脸，丰满脸颊毛、胸毛；小粉鼻；三角形耳朵、淡粉内耳；软圆爪；略 Q 版但保持猫科真实骨架。
- 外貌身份恒定。允许自然变化身体方向、四肢姿态、表情、眼神、服饰、道具、光影和镜头；服装不能把猫变成人类体态。
- 双眼或至少一只蓝眼睛尽量清晰；背影镜头可根据故事使用，但尽可能保留可识别的脸部或侧脸特征。

## 语义转视觉：先行为后道具

| 文章主题 | 视觉事件建议 | 不宜采用 |
|---|---|---|
| AI 自动化 | 猫在任务分发站推动一枚关键节点，包裹、日程、账单系统自动响应 | 坐在两个显示器中间 |
| 代码关系图 | 猫循着三维依赖线追踪关键函数，旁边的成堆文件转为整齐节点 | 仅仅堆漂浮代码面板 |
| 调试逆向 | 猫拨开装置外壳，定位内部齿轮与调用链，然后复原结构 | 整面墙无意义二进制数字 |
| UI 改造 | 猫拉开两种风格的页面材质层，露出整齐网格 | 单纯展示漂亮网页 |
| 隐形考勤 | 猫在晨光中赶到公司、被窗后目光关注 | 机械职场头像照 |
| Agent 记忆 | 猫把一次任务的记忆胶囊从旧工作台交到新工作台 | 万年云端飞跃镜头 |
| 内容创作 | 猫在街巷/书架/生活现场收集灵感并整理成卡片 | 万年伏案发呆 |

这些是思路，不是固定模板。根据文章创作新的行动故事。

## 动作导演五元组

1. 行为目的：猫现在需要解决什么？
2. 身体动作：前/后爪、躯干倾角、身体重心、尾巴、视线如何配合？
3. 互动对象：与哪个道具接触？接触后发生什么变化？
4. 情绪：好奇、专注、怀疑、欣喜、疲惫、释然等？
5. 镜头：俯拍/仰拍/侧拍/动态近景/广角、角色在画面哪侧？

低动态也必须发生真实行为，例如伸爪翻页、歪头检查、电缆附近探身。不要强行用跳跃替代细致观察。

## 画幅、文字与质量

| 类型 | 最终比例 | 目标像素 | 版式 |
|---|---:|---:|---|
| X 文章封面 | 5:2 | 2000×800 | 宽幅，简明主题，保留左右空间 |
| 正文插图 | 16:9 | 1920×1080 | 聚焦段落中的一个知识点 |

封面备选 1920×768；正文图只有明确需求才采用 3:2/4:3。输出优先 PNG，可按需要导出高质量 JPG。绝不拉伸；需要大面积换画幅时优先扩图或重新生成。

**文字策略**：默认无文字；仅用户要求时添加。建议标题不超过一行、副文案不超过一行，左右对比每侧 2–8 字，避免密集标签。代码/产品名须原样拼写；需要百分比、Benchmark 时逐项核对用户正文，不能制造新数字。文字不清楚时改用排版程序叠字。

## 基本色卡

- `#8FC9F5` 天空蓝
- `#B9D9F5` 浅蓝
- `#FFF7ED` 奶油白
- `#F7F2EC` 暖白
- `#B5A6A2` 浅灰棕
- `#6C9CCF` 点缀蓝
- `#EFA7AC` 鼻尖粉
- 主题允许少量暖金、科技青、植物绿、柔紫，不强制每次同一间蓝色房间。

## 质量控制

必须检查：角色一致性、动作真实接触、猫科关节、画面故事清晰、对比逻辑、光影层次、主体不被切脸、道具不过量、文字无错别字、无额外肢体/爪尾、最终文件尺寸可读取。仅仅“生成了横幅图”不等于已经达到 2000×800。
